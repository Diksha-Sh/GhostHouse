# Ghost House

Serverless Cloud Honeypot for Dynamic Threat Deception.

## Project Description

Ghost House is a cloud-based honeypot designed to detect and respond to different types of suspicious activity using dynamic deception.

The project uses a React frontend and a serverless AWS backend.

## Technology Stack

- React
- Vite
- JavaScript
- AWS Lambda
- API Gateway
- DynamoDB
- Vercel

## Frontend

The frontend contains:

- Decoy interface
- Attack interaction pages
- Live attack monitoring dashboard
- Attack classification display
